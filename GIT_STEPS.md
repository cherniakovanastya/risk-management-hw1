# Git і GitHub: фінальні кроки

1. Створіть на GitHub публічний репозиторій `risk-management-hw1` з README та шаблоном `.gitignore` для R.
2. Клонуйте його через RStudio: **File → New Project → Version Control → Git**.
3. Скопіюйте в клонований репозиторій вміст цього комплекту.
4. Запустіть `scripts/main_analysis.R`.
5. Вставте таблицю з `data/readme_results_table.md` у розділ «Результати» файлу `README.md`.
6. У вкладці Git позначте файли як Staged і виконайте commit:

```text
feat: add R script for VaR and ES calculation
```

7. Натисніть **Push**.
8. Перевірте, що на GitHub є скрипт, README, графік і CSV з метриками.
